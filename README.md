# SNS → 텔레그램 알림 설치 안내

X·Threads·Facebook 계정의 새 글을 30분마다 텔레그램 채널로 보냅니다.
- 한국 시간 밤 11시 30분~새벽 5시에는 보내지 않고, 그 사이 글은 새벽 5시쯤 한꺼번에 보냅니다.
- 영어 글은 무료 Google 번역으로 한국어 번역을 붙입니다. 번역이 실패하면 원문만 보냅니다.
- 비용: 0원(GitHub 공개 저장소의 무료 실행 시간 사용)

---

## 1단계. 텔레그램 준비 (5분)

1. 텔레그램에서 **@BotFather** 채팅을 열고 `/mybots` → `@vintageskully_bot` → **API Token**을 눌러 토큰을 복사합니다.
   (`123456789:AAH...` 형태. 이 토큰은 채팅에 붙여넣지 마세요.)
2. 알림을 받을 **채널 → 관리자 → 관리자 추가**에서 `@vintageskully_bot`을 넣고 **메시지 게시** 권한을 줍니다.
3. 채널 ID를 확인합니다.
   - 공개 채널이면 `@채널주소`(예: `@my_feed`)를 그대로 쓰면 됩니다.
   - 비공개 채널이면, 채널에 아무 글이나 하나 올린 뒤 브라우저에서
     `https://api.telegram.org/bot<토큰>/getUpdates` 를 엽니다.
     `"chat":{"id":-100...` 에 나오는 **-100으로 시작하는 숫자**가 채널 ID입니다.

## 2단계. GitHub 저장소 만들기 (10분)

1. https://github.com 에 가입 또는 로그인합니다.
2. 오른쪽 위 **+** → **New repository**
   - 이름: `sns-feed` (아무거나 괜찮음)
   - **Public** 선택 (무료 실행 시간이 무제한입니다. 비밀번호·토큰은 3단계의 Secrets에 들어가서 공개되지 않습니다.)
   - **Create repository**
3. 생성된 페이지에서 **uploading an existing file** 링크를 누르고 아래 4개 파일을 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
   - `feed.py`, `accounts.txt`, `requirements.txt`, `state.json`
4. **Add file → Create new file**을 누릅니다.
   - 파일 이름 칸에 정확히 `.github/workflows/feed.yml` 입력 (`/`를 치면 폴더가 자동으로 만들어집니다)
   - 내용에 `feed.yml` 파일 내용을 전부 붙여넣고 **Commit changes**를 누릅니다.

## 3단계. 비밀 정보 넣기

저장소 **Settings → Secrets and variables → Actions → New repository secret**에서 아래 항목을 추가합니다.

| 이름 | 값 | 필수 |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | 1단계에서 복사한 봇 토큰 | 필수 |
| `TELEGRAM_CHAT_ID` | `@채널주소` 또는 `-100...` 숫자 | 필수 |
| `X_COOKIES` | X 로그인 쿠키 (아래 방법) | X 글을 받으려면 필요 |
| `FB_COOKIES` | 페이스북 로그인 쿠키 (아래 방법) | 페이스북 글을 받으려면 필요 |

Threads는 로그인 없이 동작합니다.

### 쿠키 넣는 방법 (X, 페이스북 각각)
1. PC 크롬에 **Cookie-Editor** 확장 프로그램을 설치합니다.
2. 크롬에서 x.com(또는 facebook.com)에 로그인된 상태로 그 사이트를 엽니다.
3. Cookie-Editor 아이콘 → 아래쪽 **Export** → **JSON**을 누르면 클립보드에 복사됩니다.
4. 복사한 내용을 그대로 Secret 값에 붙여넣습니다 (`X_COOKIES` 또는 `FB_COOKIES`).
5. 그 뒤 그 브라우저에서 **로그아웃하지 마세요**. 로그아웃하면 쿠키가 무효가 됩니다(창만 닫는 건 괜찮습니다).

## 4단계. 첫 실행 (테스트)

1. 저장소 **Actions** 탭 → 처음이면 초록 버튼 **I understand… enable**을 누릅니다.
2. 왼쪽 **SNS to Telegram** → **Run workflow** → **테스트: 계정마다 최신 글 1개씩 보내기**를 체크합니다
   (밤이라면 **밤 시간에도 실행**도 체크) → **Run workflow**
3. 2~5분 뒤 텔레그램 채널에 계정별 최신 글과 **"✅ 설정 완료 … N/N 계정 수집 성공"** 메시지가 옵니다.
   - 실패한 계정은 이유와 함께 표시됩니다. 그 메시지를 캡처해서 보내 주시면 고쳐 드립니다.

이후로는 자동으로 30분마다 돌아갑니다. 따로 할 일은 없습니다.

## 계정 추가와 삭제
저장소에서 `accounts.txt` → 연필 아이콘으로 편집 → 주소를 한 줄에 하나씩 추가하거나 지운 뒤 Commit하면 됩니다.

## 알아두실 점
- GitHub 예약 실행은 몇 분에서 길게는 15분 이상 늦게 시작될 수 있습니다.
- X와 페이스북은 자동 접속을 싫어해서 가끔 **보안 확인이나 로그아웃**이 걸릴 수 있습니다. 3시간 연속 실패하면 텔레그램으로 ⚠️ 알림이 옵니다. 그때 쿠키를 다시 복사해 Secret을 갱신하면 됩니다.
  계정이 잠기거나 정지될 위험이 조금 있으니, 걱정되면 X·페이스북은 부계정으로 로그인한 쿠키를 쓰세요.
- 사이트 화면 구조가 바뀌면 수집이 멈출 수 있습니다. 그때는 실패 메시지를 보내 주세요.
